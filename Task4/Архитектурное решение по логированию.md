# Архитектурное решение по логированию

## 1. Мотивация

Проблемы клиентов разбираются со слов. Разработчики тратят много времени на поиск причин ошибок.

**Технические метрики:**
- MTTD: с 30-60 мин до 2-5 мин
- MTTR: с 4-8 часов до 30-60 мин
- Время расследования: с 2-3 часов до 15-30 мин

**Бизнес-метрики:**
- Снижение простоя на 40-60%
- Снижение эскалаций на 50%
- Снижение повторных обращений на 30-40%

## 2. Источники логов

Shop API, CRM API, MES API, RabbitMQ, Frontend (критичные ошибки)

## 3. Логи INFO уровня

**Shop API:** создание заказа, изменение статуса, загрузка файла, отправка в очередь
**CRM API:** получение из очереди, изменение статуса, подтверждение производства, закрытие заказа
**MES API:** получение заказа, расчет стоимости, назначение оператора, изменение статуса, отправка
**RabbitMQ:** публикация, доставка, отказ доставки, DLQ
**Frontend:** критичные действия, ошибки API

**Формат:** timestamp, order_id, customer_id/user_id, action, context

## 4. Другие уровни

**DEBUG:** детали алгоритмов, SQL (по требованию)
**WARN:** превышение времени расчета, retry, медленные запросы, лимиты
**ERROR:** ошибки БД, RabbitMQ, S3, бизнес-логики, парсинга 3D
**FATAL:** падение сервиса, недоступность БД/RabbitMQ

## 5. Приоритеты внедрения

**Первая очередь (2 недели):** MES API, RabbitMQ, Shop API
Причина: 80% жалоб связаны с потерянными заказами

**Вторая очередь (2 недели):** CRM API, MES Frontend

**Третья очередь (1 неделя):** Shop Frontend, CRM Frontend

## 6. Предлагаемое решение

**Стек:** OpenSearch + Fluentd + OpenSearch Dashboards

**Компоненты:**
1. Fluentd Agent: сбор логов, парсинг JSON, обогащение, отправка
2. OpenSearch Cluster: 3 ноды, индексы с ротацией
3. OpenSearch Dashboards: поиск, дашборды, алерты

**Формат:** структурированный JSON с полями timestamp, level, service, trace_id, order_id, message, context

**Связь с трейсингом:** trace_id в логах, переходы между Jaeger и логами

**Реализация:** 6 недель (1 неделя настройка + 5 недель внедрение)

## 7. Безопасность

**Запрещено:** пароли, токены, платежные данные, полные имена, email, телефоны
**Разрешено:** идентификаторы, статусы, технические параметры

**Доступ:**
- DevOps: полный доступ
- Backend: доступ к своим сервисам
- Support: read-only INFO/WARN/ERROR
- TechLead/PM: агрегированные данные

**Аутентификация:** LDAP/AD, VPN, audit log

## 8. Политика хранения

**Индексы:** отдельный на сервис (`shop-api-YYYY-MM-DD`), ротация ежедневно

**Сроки:**
- DEBUG: 3 дня
- INFO: 30 дней (7 hot + 23 warm)
- WARN: 60 дней (14 hot + 46 warm)
- ERROR: 90 дней (30 hot + 60 warm)
- FATAL: 365 дней (90 hot + 275 warm)

**Объем:** ~200 GB/месяц, ~400 GB активных данных

## 9. Анализ логов

**Алертинг:**
- Critical: ERROR > 10/мин, любой FATAL, потеря сообщений, отсутствие логов > 2 мин
- Warning: WARN > 50/мин, медленные запросы > 20/мин, retry > 100/мин

**Поиск аномалий:**
- Спайки: рост заказов 100→1000/час (DDoS?)
- Отсутствие событий: нет заказов > 10 мин
- Паттерны: один customer 100+ заказов/мин (бот), много ошибок одного endpoint

**Дашборды:**
1. Operations: логи по уровням, top ошибок, latency, статусы
2. Business: воронка заказов, время обработки, проблемные заказы
3. RabbitMQ: публикации/доставки, retry, DLQ, latency

## 10. Сравнение технологий

| Критерий | ELK Stack | OpenSearch | Loki | Splunk |
|----------|-----------|------------|------|--------|
| Лицензия | Elastic (ограничения) | Apache 2.0 | AGPL 3.0 | Проприетарная |
| Стоимость | Базовая бесплатно | Бесплатно | Бесплатно | $150+/GB/год |
| Индексация | 10-20K/sec | 10-20K/sec | 50-100K/sec | 20-30K/sec |
| Ресурсы | RAM 8GB+ | RAM 8GB+ | RAM 2GB+ | Средне |
| Поиск | Полнотекстовый | Полнотекстовый | Label-based | Очень мощный |
| Grafana | Плагин | Плагин | Нативная | Плагин |
| Обучение | Средне | Средне | Легко | Сложно |
| 200GB/месяц | Да | Да | Да | Нет (дорого) |

**Выбор: OpenSearch**

Плюсы: открытая лицензия, совместимость с Elasticsearch API, AWS поддержка, мощный поиск
Минусы: требует ресурсы (8GB RAM), нужна экспертиза

Альтернативы: Loki (легковесный, но без полнотекстового поиска), ELK (ограничения лицензии), Splunk (дорого)
